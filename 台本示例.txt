# 台本示例 · 每行 = 一个独立合成的片段

# 格式说明：
#   1. 想在哪里停就换一行，段间留白由后期脚本统一控制
#   2. # 开头是注释，不会被念出来
#   3. 不要写括号里的舞台说明，TTS 会把括号里的字念出来；语气靠标点和断句
#   4. 数字写中文（"三十秒"而不是"30秒"），念出来才对
#   5. 短句节奏不稳就同文多抽几条挑最好的，参考 examples/take_variants.py

你好呀！我是你的专属通话员，今天也要元气满满哦。

今天是星期六，天气很好，我们去公园放风筝吧。
等你完成今天的任务，记得回来向我汇报哦。
没有困难的事情，只有勇敢的小朋友。通话结束。
